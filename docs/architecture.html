System Architecture

Factory Inventory Management System

A full-stack demo for the Claude Code workshop. A Vue 3 single-page app talks over HTTP to a FastAPI backend, which serves filtered views of mock data loaded from JSON files into memory at startup. There is no database, no authentication, and no persistence between restarts.

System Overview

Three tiers, all running locally. The browser loads the Vue bundle from the Vite dev server, then every data request goes directly to FastAPI on a different port. CORS is wide open to allow this in development.

Reactivity pattern used in every view

Raw API responses land in ref()s such as allOrders or inventoryItems. Everything shown on screen (totals, chart series, low-stock lists) is a computed() over those refs. A watch on the four filter refs calls the loader again, so the server does the filtering and the client only reshapes.

Backend API

All endpoints are read-only. Filter query params are optional; the string all is treated the same as absent. Category and status match case-insensitively; warehouse matches exactly.

Pydantic response models

InventoryItem, Order, DemandForecast, BacklogItem, PurchaseOrder, CreatePurchaseOrderRequest. Dashboard, spending, and report endpoints return untyped dicts. When a JSON field changes, the matching model must change too or validation fails at response time.

Time filtering

filter_by_month does a substring match of YYYY-MM against order_date. Values starting with Q expand through QUARTER_MAP to three months. Inventory has no date field, so the month filter is ignored for inventory and only shapes the orders side of the dashboard.

Data Flow: one filtered request

What happens when a user picks a warehouse in the filter bar while viewing the Dashboard.

Step by step

  1. User changes a select in FilterBarThe select is bound with v-model to a ref exported by useFilters.
  2. Shared ref updatesBecause the refs are module-level, every mounted view sees the same value instantly.
  3. View's watcher firesEach view watches the four refs and calls its loader, which typically issues several requests in parallel with Promise.all.
  4. api.js builds the URLgetCurrentFilters() renames location to warehouse and period to month. Any value equal to all is omitted.
  5. FastAPI filters and validatesHandlers run apply_filters and, for orders, filter_by_month. Typed endpoints validate the result through response_model.
  6. Client reshapesThe response is stored in a ref. Computed properties derive totals, chart series, and modal detail rows. No client-side filtering repeats the server's work.

Startup sequence

  1. Backend importmain.py imports mock_data, which reads all seven JSON files synchronously into memory.
  2. Uvicorn binds :8001CORS middleware attached with wildcard origins. OpenAPI schema available at /docs.
  3. Vite serves :3000Browser loads index.html, then main.js creates the router and mounts App.vue.
  4. App shell mountsuseI18n restores locale from localStorage. App.vue also calls api.getTasks() for the tasks modal.
  5. First view loadsThe routed view's onMounted triggers the initial fetch with all filters set to all.

Developer Tooling

Run

./scripts/start.sh installs missing deps, starts both servers in the background, and writes PIDs to /tmp. stop.sh reverses it. Manual: uv run python main.py and npm run dev.

Test

From tests/, run uv run pytest -v. The conftest.py fixture adds server/ to the path and wraps the app in TestClient, so tests hit the real handlers with the real JSON fixtures.

Observations

Things worth knowing before changing code. None block the demo, but they explain some behavior you may see.

Gap Frontend calls with no backend route

api.js defines getTasks, createTask, toggleTask, deleteTask, createPurchaseOrder, and getPurchaseOrderByBacklogItem. The server has no /api/tasks or /api/purchase-orders routes, so these return 404. App.vue calls getTasks on mount. The CreatePurchaseOrderRequest model exists but is unused.

Inconsistency Reports bypasses api.js

Reports.vue imports axios directly with a hard-coded http://localhost:8001 base URL instead of going through api.js. Changing the API host means editing two places.

Unused Backlog view

views/Backlog.vue is complete but not registered in the router or nav. Backlog data surfaces only through the Dashboard and its detail modal.

By design Demo-only posture

Wildcard CORS, no auth, no pagination, no persistence, and a fixed USD to JPY rate of 150. The revenue goal used on the dashboard is $800K per month or $9.6M when all months are selected.
